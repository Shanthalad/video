🎥 Video Player Page
This project contains a simple HTML page that allows users to watch a video directly in the browser using the HTML5 <video> tag.

📄 File Included

index.html (or watch-video.html) – HTML page with embedded video player
video.mp4 – Video file (must be present in the same folder)

🚀 Features

Uses HTML5 Video Player
Supports .mp4 video format
Play, pause, volume, and fullscreen controls enabled
Works in all modern browsers (Chrome, Edge, Firefox)

🛠️ How to Use
Clone or download this repository
Place your video file in the same folder as the HTML file
Example:

project-folder/
├── index.html
└── video.mp4
Open index.html in any web browser
Click Play to watch the video
